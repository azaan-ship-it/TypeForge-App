# TypeForge

**Type faster. Race friends. Level up your robot.**

A ByteForge Studios app.

## Download

**[Download TypeForge for Windows](https://github.com/azaan-ship-it/TypeForge-App/releases/latest/download/TypeForge-Setup-1.0.0.exe)**

Or grab it from the [Releases](https://github.com/azaan-ship-it/TypeForge-App/releases) page. Windows may show a SmartScreen warning because the app isn't signed yet: click **More info → Run anyway**.

## Play on the web

**[Open TypeForge in your browser](https://playtypeforge.onrender.com)**, no install needed. (The free server sleeps when nobody is using it, so the first load can take about a minute.)

## Features

- **Type**: time, words, quote, code or custom text tests with WPM, accuracy and a speed chart
- **Race**: race bots, your own ghost, or friends in live PIN rooms, with Nitro boosts
- **Academy**: 61 lessons that teach every key, with mini-games between them
- **Shop**: 179 robots, mechs, trails, titles, banners and themes, plus a Daily Shop and crates
- Friends, quests, streaks and 34 achievements
